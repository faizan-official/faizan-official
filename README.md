## 🛠️ Things I've Shipped

A few things I've worked on over the years:

### 🏠 CoLivingPro

A property management SaaS built for coliving and shared-housing operators.

I built the product end-to-end, including the backend, frontend, pricing logic, listing management, lead workflows, billing, integrations, and deployment infrastructure.

**React · Django · PostgreSQL · Celery · Stripe · AWS · Hetzner**

[Visit CoLivingPro →](https://colivingpro.io)

### 🤖 SAP Assistant

An AI assistant built for a German SAP consultancy, combining a conversational interface with knowledge-base search and AI-generated responses.

**Python · Django · Dialogflow · AI · Stripe**

[Visit SAP Assistant →](https://sapasistant.com)

### ⚡ FastLog

A small developer tool I built because I wanted a better way to work with large log files.

FastLog runs entirely in the browser, indexes logs locally, and supports JSON/NDJSON, regex search, filtering, and offline use.

**JavaScript · PWA · Indexed Search**

[Try FastLog →](https://fastlogviewer.com)

### 🔧 Invico

A free, privacy-first invoice generator for freelancers and small businesses. Create invoices, manage clients, and export PDFs without an account or subscription.

**No signup · No subscription · No backend · Works offline · Free forever**

[Visit Invico →](https://useinvico.com)
